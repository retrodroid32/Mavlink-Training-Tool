How to use this workbook

Learn → Experiment → Record → Quiz

Open the matching module in MAVLink Academy. Read its three lessons. Then use the interactive browser lab to answer each workbook question. Complete a five-question randomized knowledge check after each module. Passing is four correct answers out of five (80%).

Suggested workflow

Read the lesson and underline new terms.

Run the interactive lab, recording the exact values you observe.

Explain results in your own words; avoid memorizing only button positions.

Take the quiz; revisit the lab for any missed concept.
